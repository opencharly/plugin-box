```console
$ grep -rn 'spec\.CandyAlias\|spec\.CandyVolume' --include=*.go . | grep -v Resolved | grep -v source_invariant_test.go | grep -c ''
```

**Three, not zero — and the three are deliberate.** Every one is inside `source_invariant_test.go`, the test that NAMES the authored defs in order to forbid them. My earlier revision pasted `0` from a sweep run before that test existed, which is the same stale-evidence mistake this PR has already been blocked on twice.

So the claim this PR is actually about, stated precisely: **no production file names the authored defs** — the only references left in this repo are the ones whose job is to keep it that way.

**Why the resolved form is the right one.** A reader decodes a body that has **already been validated**: the plugin validates the authored shape, the host encodes it, and the consumer decodes the resolved envelope. That is the three-way split `DESIGN.md` 3.1 + 10.2 require together, and the precedent is `spec/charly_names.go`'s `VmSpec = ResolvedVm`.

**What this completes.** With it, **no repository outside `spec` names the authored defs any more** except `#Candy` itself. `sdk` stopped in `#546` (verified by a pasted sweep there); this repo stops now. Which means `#CandyAlias` and `#CandyVolume` are finally **movable** to `plugin-candy-kind`.

**The change cannot be covered behaviourally, and saying so is the honest part.** The resolved twins are **wire-compatible** with the authored defs by design — same fields, same JSON — so a round-trip passes identically whichever type a site names. I measured it: reverting one decode target to `spec.CandyAlias` leaves **every behavioural test in this package green**.

So the property that actually changed is **which type the code names**, and that is a property of the source. `source_invariant_test.go` reads this package's non-test files and fails if any of them names the authored defs:

```console

ok  	github.com/opencharly/plugin-box/candy/plugin-box	0.092s
```

That is the "coverage that fails without the change" R7 asks for — it is just not the *kind* a round-trip would give. And it guards the thing that matters for the move: a decode target still naming the authored defs would travel with them, and no behavioural test would notice until the move broke the build somewhere else.
