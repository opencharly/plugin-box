# 2026.282.1127 — fix(validate): reject a base: that cannot be an image name

## Summary

`charly#853`, leg 1: **`charly box validate` must reject a `base:` that cannot be an image name.** The rule
checked only the `base:`/`from:` *relationship*, never the `base:` **value**, so `validate` reported OK for a
box that cannot build and `box build` then died in `c/images` (`parsing image name …: invalid reference
format`). This is the first leg; the second (checking `from:` values the same way) is `plugin-box#31`'s row.

| `candy/plugin-box/validate_config_rules.go` | the clause: a `base:` beginning with `@` is charly's NAMESPACE-ref syntax, syntactically impossible as an image name, so it is an ERROR and needs no registry lookup |
| `candy/plugin-box/validate_config_rules_test.go` | the four-case table (fully-qualified → accept; bare short name → accept, host-dependent; empty → accept, scratch; `@github…` → reject) |
