# 2026.288.1319 — docs(workflow): make the caller's comment true wherever it is copied

## Summary

Makes the org's canonical `tag-on-merge` caller comment **true wherever it is copied**, by attributing each
measurement to where it came from instead of assuming the reader's context.

The file is copied verbatim into other repos, and its comment told the story behind the trigger design using
facts about **this** repository — `measured in this repo across 8 merges and 17 schedule runs`, `PR #3's tag
landed 4+ hours late`, `PR #7's tag was still missing 30 min after merge`, `for PR #8`. Every one is true here
and false in a copy: those merges, schedule runs and PR numbers are not the copying repo's own.

- the header no longer claims *every* opencharly repo carries the file, which is not true (27 of 29);
- the trigger RCA is attributed to where this caller originated, not to "this repo";
- the auto-merge event example is marked `(upstream PR #8)`;
- the cron-drift evidence is stated without this repo's PR numbers.

**Measured cost of the old text**: the caller was rolled out to 25 repositories, each of which then asserted
those sentences as its own history. The first of them took five review rounds, and the same divergence class was
measured present in **all 25 copies**. This is the producer-first fix for that: correct the source, and the
copies that follow are correct by construction.

Closes #48
