# 2026.317.2259 — refactor(validate): judge kind:local templates through the contract envelope

## Summary

`opencharly/spec#304` unit 4, a consumer leg. The authored `#Local` body — and the Go type generated from it — moves into the plugin that **serves** the kind (`opencharly/plugin-substrate#34`, merged), so a consumer outside that plugin must stop holding the authored type. This package's `validateLocalTemplates` decodes each authored `kind:local` template and reads its `candy:` stack; it now decodes into the contract's own **`spec.ResolvedLocal`** envelope, the shape a RESOLVED local body has everywhere else (the kernel's `OpResolve` reply carries the same fields).

The rule's judgement is unchanged: a missing `candy:` stack, an unknown bare candy and an unresolvable remote candy ref each still produce their finding, and a body that will not decode is still a host/load concern this rule stays quiet about. A new test pins all five outcomes.

