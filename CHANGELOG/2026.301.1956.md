# 2026.301.1956 — test(skills): the vacuity guard takes the claims it judges

Closes #71

## Summary

Head `ec98ba5f0cfc3c0b011320302ca5622351507b34` — the commit this PR pushes: **1 file changed, 13 insertions(+), 9 deletions(-)**.

**The finding.** opencharly/plugin-box#70's validator review raised one non-blocking observation: the control computes the body's usage claims into `claims` and then calls `skillDocIsVacuous(body, command)`, which computes them AGAIN — the same claims, read twice, for one decision.

**The RCA.**

- **Mechanism** — the guard took the BODY and the COMMAND, so it re-derived the claims its caller had already derived. The control needs those claims for the loop below, and the guard needs only their emptiness, so one body was read twice for one decision.
- **Missed control** — no rule held the control to compute a derived value ONCE. The rule this control enforces is that the vacuity rule has ONE implementation, and a rule that re-derives its own input sits one step further from the thing it judges.
- **Blast radius** — this control's subject is the corpus of this repo's verb skills, published VERBATIM into the opencharly/marketplace corpus. The redundancy itself changes no verdict: both reads see the same body and the same command, so they agree. The blast radius is therefore the CONTROL's own standing, not the corpus's content — a rule that re-derives its own input is one step away from judging something else.
- **Root fix** — the guard takes the CLAIMS it judges, so the control computes them once and hands the same slice to both the guard and the loop. The rule stays one implementation, and the red arm still fires on a body that never invokes the command it documents.

**This is the successor to opencharly/plugin-box#70**, which landed the guard and its red arm. #70 merged before this fix could be pushed onto it, so the fix is its own change here, off a fresh `origin/main` — the successor's body names its predecessor, and #71 carries the finding.

**What lands.** One file:

| file | what it carries |
|---|---|
| `candy/plugin-box/skill_doc_flags_test.go` | the vacuity guard taking the claims it judges, so the control reads a body's claims once |

No verb, no flag, no published prose, and no grammar changes: this is a tidy-up of the control that guards the corpus, and the guard's behaviour is unchanged.
