# 2026.327.1113 — docs(build): the scratch stage carries only what a candy's plan reads

## Summary

`opencharly/sdk#625` changed two behaviours this skill described inaccurately, and the change is
docs-only:

- a candy nothing copies from **no longer gets a scratch stage** at all;
- an **INLINE candy** (declared in the project's root `charly.yml`, whose directory is the build
  root) is staged by the **exact paths its plan names**, never with a whole-project `COPY ./ /`.

The context-ignore section's "generated Containerfiles COPY only from `candy/`, `templates/`,
`.build/`" line was therefore incomplete. The prose now names the three COPY sources a normal candy
uses, states the inline-candy rule and why the whole-root COPY was a hazard (the entire project
tree, protected only by a denylist), and records that a consumed candy whose sources cannot be
expressed fails loudly by path rather than being silently served the project.
