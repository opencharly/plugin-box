**The record for #60 carried a claim that the landing falsified, so the correction goes in the record
itself, the way #75 corrected `CHANGELOG/2026.302.0039.md` — because the record is where the next
reader looks.**

The entry for #60 ends with a paragraph on attribution, and it says:

> **Two trailers, honestly.** The branch's own content commit `7e4d5fd` was authored in an earlier
> session and keeps ITS trailer (`DeepSeek Harness deepseek-v4.1-flash`); the pushed head `1756c8c`
> is a merge commit written by this session and carries this session's trailer. GitHub's squash
> composes the landed message from the branch's commit messages in order, so the landed commit
> carries both — each session's own authorship, neither overwritten.

**Measured on the landing, the last sentence of that is false.** GitHub composes a squash message
from the branch's **non-merge** commit messages:

```
$ git log -1 --format='%B' ee7962bb93136061df5ddb908ab9de07dc6825a6 | tail -4
Assisted-by: DeepSeek Harness deepseek-v4.1-flash (documentation reviewed)

Co-authored-by: Andreas Trawoeger <atrawog@gmail.com>

$ git log -1 --format='%B' ee7962bb93136061df5ddb908ab9de07dc6825a6 | grep -c 'Merge remote-tracking branch'
0

$ git log -1 --format='%B' 1756c8cfd713bc7735664a31ac26a63e8c456fc5 | tail -1
Assisted-by: Claude Code minimax/minimax-m3.1-flash:cloud (documentation reviewed)
```

So the landed commit carries **ONE** trailer — the content author's — and the merge commit's own
message, with the takeover session's trailer, is not carried into it. The landed attribution is the
content author's, which is correct for the change that commit carries.

**The record now says so, and says when it changed.** The false sentence is replaced by the
measurement, and a dated note records the correction inside the entry itself: a changelog that
silently changes its own wording is a changelog nobody can trust.

**The PR body was corrected too, and that alone was not enough.** The body of #60 is the source the
changelog is generated from, so it now carries the same text. But a later body edit never
regenerates the changelog, which is why the file needs a change of its own.
