# 2026.243.1718 — fix(reconcile): rewrite pins in place, not by re-serializing the document

## Summary

**The remedy the workflow rule prescribes for a version-mismatch warning is currently unusable.**

`charly box reconcile` aligns cross-repo `@github` pins so a repo resolves to one version — the
git-workflow rule names it as the fix for a `resolved to multiple versions` warning. Run on a
160KB `charly.yml`, it changed the 4 pins it reported and **405 lines in total**.

Pass 2 mutated the parsed scalar and then `yaml.Marshal`'d the whole document, round-tripping
every *other* node through the emitter. yaml.v3 does not reproduce a **folded** block scalar
(`>-`): it re-emits the body as one long line and drops the blank lines around it. Every
authored `description:` in the file was reflowed, across entities the reconcile had no reason to
touch:

```
-            Sole proof of the punktfunk CONTAINER venue and of the `punktfunk:` check verb
-            against a live host. Builds punktfunk-host on cachyos, deploys it with a headless
-            sway compositor, and runs the candy's baked package/key/host.env/wrapper checks
+            Sole proof of the punktfunk CONTAINER venue and of the `punktfunk:` check verb against a live host. Builds punktfunk-host on cachyos, …
```

A **literal** scalar (`|-`) round-trips byte-exactly, which is why the damage looks selective and
went unnoticed: files with only literal prose are unaffected.

The consequence is circular — the diff the remedy generates is itself a review blocker, and it
silently reformats prose someone wrote deliberately. So the warning it exists to clear cannot be
cleared with it.

## What changed

A pin is always a single-line scalar, so the rewrite is now **line-local**: the original bytes
are retained from pass 1, and only the lines carrying a changed ref are touched. Every other byte
is preserved exactly.

Where the node position and the bytes disagree, `applyPinEdits` returns an error rather than
replacing the value somewhere else — a blind fallback would corrupt the file it was asked to
edit.

```
 candy/plugin-box/reconcile.go             |  52 +++++++++++---
 candy/plugin-box/reconcile_format_test.go | 115 ++++++++++++++++++++++++++++++
 2 files changed, 159 insertions(+), 8 deletions(-)
```

Generated from `git diff --stat origin/main...HEAD`.

## How tested

```
$ go vet ./... && go test ./...

```

**Executed live, on the file that exposed it.** charly was built against this branch
(`go mod edit -replace …/plugin-box/candy/plugin-box`, then `task build:binary`; the binary
carries the new path — `strings bin/charly | grep 'reported at line .* outside the'` → 1 match),
and `charly box reconcile` was run on the same 160KB project. It reported the **same 4 pins** as
before the change:

```
before   2 files changed, 170 insertions(+), 235 deletions(-)
after    2 files changed,   4 insertions(+),   4 deletions(-)
```

and the after-diff is exactly the four pin rewrites, nothing else:

```
-            - '@github.com/opencharly/pod-pipewire:v2026.239.1555'
+            - '@github.com/opencharly/pod-pipewire:v2026.243.0508'

+            - '@github.com/opencharly/layer-punktfunk:v2026.242.1658'
```

**Three guards:**

- **only the pin lines change** — the property the fix exists to hold; it also asserts the line
  count is unchanged, so a dropped blank line fails it.
- **the round trip reflows authored prose** — the negative control, pinning *why* the code
  exists. It logs the damage (`647 bytes -> 610 bytes`) and would skip itself if yaml.v3 ever
  round-tripped faithfully, so it cannot silently become vacuous.
- **a position mismatch refuses** — line past the end, line zero, and a value not on the named
  line all return an error and no output.

**The fixture uses a FOLDED scalar deliberately.** An earlier revision of this test used a
literal one; yaml.v3 round-tripped it byte-exactly, so the negative control **SKIPPED** and the
suite passed while proving nothing. That is recorded here because the skip was invisible in
`go test` output without `-v` — the failure mode this repo should not repeat.

## Rulebook compliance

- **R1 (RCA)** — root-caused to yaml.v3's folded-scalar emission by round-tripping the real file
  and diffing, not by guessing; the literal-vs-folded distinction explains why the damage looked
  selective.
- **R3 (no duplication)** — one rewrite path; the reporting (`rewrites`) is unchanged.
- **R4 (no workarounds)** — the emitter is not configured or post-processed; the re-serialization
  is removed. No retries, no formatting cleanup pass.
- **R5 (delete legacy)** — the `yaml.Marshal` write path and its now-unused `fileChanged` flag are
  removed in this PR, not deprecated.
- **R6 (git safety)** — feature branch, no force-push, no hook bypass.
- **R7 / R10 (prove the gate)** — `go vet` + full package tests on the committed tree, plus the
  changed code compiled into charly and run against the 160KB file with the resulting diff
  pasted above.
