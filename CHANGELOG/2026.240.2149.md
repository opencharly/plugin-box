# 2026.240.2149 — fix(box): dedupe the bake_plugin name conflict + remove a leftover DEBUG print

## Summary

Fixes the plugin-mcp conflict blocking the Phase-4 distro sweep: `validateRemoteCandies` flagged a remote candy name conflict whenever the same name came from two different `RepoPath` values. The bake_plugin mechanism (a candy's `bake_plugin:` ref pulling an out-of-tree plugin candy into its composing images) makes the baked plugin appear under the BAKING repo's path while the standalone repo provides it directly — the same underlying repo, not a genuine clash.

The fix adds `bakePluginSibling`, which dedupes the case where some candy in the baking repo carries a `bake_plugin:` ref pointing at the other provider repo.
